> A curated list of tools, integrations, tutorials, dashboards, APIs, resources, and best practices for Google Analytics.

Google Analytics is one of the most widely used web and app analytics platforms, helping organizations understand user behavior, measure marketing performance, optimize digital experiences, and support data-driven decision making.

This list is intended for marketers, analysts, business owners, product managers, SEO professionals, developers, researchers, and anyone working with Google Analytics.

## APIs & Developer Tools

Developer resources for accessing and automating analytics workflows.

- [Google Analytics Data API](https://developers.google.com/analytics/devguides/reporting/data/v1) — Programmatic access to GA4 data.
- [Google Analytics Admin API](https://developers.google.com/analytics/devguides/config/admin/v1) — Administrative API for GA4 properties.
- [Google APIs Explorer](https://developers.google.com/apis-explorer) — Interactive API testing platform.
- [Google Analytics Query Explorer](https://ga-dev-tools.google/query-explorer/) — Analytics query testing tool.
- [Google Cloud SDK](https://cloud.google.com/sdk) — Command-line tools for Google Cloud services.
- [MCP Server for Google Analytics](https://github.com/modelcontextprotocol/servers) — Community projects enabling analytics access through MCP.
